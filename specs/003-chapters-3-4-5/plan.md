**Branch**: `003-chapters-3-4-5` | **Date**: 2025-11-30 | **Spec**: [spec.md](./spec.md)

## Summary

Create three comprehensive textbook chapters covering robot simulation fundamentals (Gazebo), ROS 2 integration, and advanced AI-powered simulation (NVIDIA Isaac Sim, Unity ML-Agents). Content will be written in Markdown with MDX support, include 12+ executable Python code examples, integrate LaTeX math rendering via KaTeX, and cite official documentation for all external tools. This expands the existing Physical AI & Humanoid Robotics textbook (Chapters 1-2 complete) with practical, industry-standard simulation content.

## Technical Context

**Language/Version**: Markdown with MDX v3, Python 3.10+, C++ (optional examples)
**Primary Dependencies**: Docusaurus v3.6.3, KaTeX, remark-math@6, rehype-katex@7, @docusaurus/theme-mermaid
**Storage**: Static markdown files in frontend/docs/chapter3/, chapter4/, chapter5/, SVG diagrams in frontend/static/img/
**Testing**: Manual browser validation, Docusaurus build test, code example execution verification
**Target Platform**: Web (Docusaurus static site), Ubuntu 22.04 (for code examples)
**Project Type**: Web application (frontend content only, no backend for this feature)
**Performance Goals**: Page load <2s, build time <3min for all chapters
**Constraints**: Code examples must work on Ubuntu 22.04 with ROS 2 Humble, fallback instructions for Windows/WSL2
**Scale/Scope**: 3 chapters (~15-20 KB each), 12+ code examples, 6-8 diagrams, 3 major simulation platforms (Gazebo, ROS 2, Isaac Sim/Unity)

## Phase 0: Research & External Dependencies

### Research Areas

1. **Gazebo Installation and Setup** (Chapter 3)
   - Decision: Gazebo Harmonic (latest) vs. Gazebo Classic
   - Rationale: Need to determine which version to prioritize in content
   - Alternatives: Cover both, or recommend one with mentions of the other

2. **ROS 2 Version and Compatibility** (Chapter 4)
   - Decision: ROS 2 Humble (LTS) vs. Iron/Jazzy (newer)
   - Rationale: LTS support until 2027, most stable for educational content
   - Alternatives: Iron (shorter support), Jazzy (too new, less documentation)

3. **Gazebo-ROS 2 Integration** (Chapter 4)
   - Decision: gz_ros2_control vs. gazebo_ros2_control
   - Rationale: Package naming changed with Gazebo Harmonic
   - Alternatives: Document both for backward compatibility

4. **NVIDIA Isaac Sim Access** (Chapter 5)
   - Decision: Isaac Sim via Omniverse (free) vs. Isaac Gym standalone
   - Rationale: Educational license, installation requirements
   - Alternatives: Focus on Gazebo if Isaac Sim has licensing barriers

5. **Unity ML-Agents Version** (Chapter 5)
   - Decision: Unity ML-Agents Release 20 (latest) vs. Release 18 (stable)
   - Rationale: Need stable version with good documentation
   - Alternatives: Mention both, provide links to version-specific docs

6. **Code Example Format** (All chapters)
   - Decision: Python 3.10+ type hints, NumPy-style docstrings
   - Rationale: Match existing Chapter 2 style
   - Alternatives: Simpler code without type hints (rejected for consistency)

7. **URDF vs. USD** (Chapters 3 and 5)
   - Decision: Introduce URDF in Chapter 3, USD in Chapter 5
   - Rationale: URDF is ROS/Gazebo standard, USD is Isaac Sim standard
   - Alternatives: Focus only on URDF (rejected, need USD for Isaac Sim)

## Risks & Mitigation

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Version incompatibility (ROS 2 + Gazebo) | Medium | High | Document tested version combinations (ROS 2 Humble + Gazebo Harmonic), provide compatibility matrix |
| Isaac Sim licensing restrictions | Low | Medium | Focus on free educational access, provide Unity ML-Agents as alternative |
| Code examples fail on Windows | Medium | Medium | Provide WSL2/Docker instructions, note Ubuntu 22.04 as primary target |
| Gazebo installation errors | Medium | High | Include troubleshooting section in quickstart.md, link to Gazebo official troubleshooting |
| Students lack GPU for Isaac Sim | High | Low | Make Isaac Sim optional (Chapter 5 is P2), emphasize Gazebo as primary tool |
| External documentation links break | Low | Low | Use official docs (ros.org, gazebosim.org, nvidia.com), verify during citation validation |
